# Assets Directory

This directory contains static media and downloadable assets for Atharva Tayade's personal portfolio website (`AtharvaTayade2005.github.io`).

## Required Files

Place your personal files in this directory with the exact filenames listed below:

1. **`resume.pdf`**
   - **Purpose:** Downloadable resume linked to the "Download Resume" button in the navigation bar and hero CTA.
   - **Recommended Format:** Standard PDF format (single-page or two-page resume).
   - **Destination:** `assets/resume.pdf`

2. **`profile.jpg`** (or `profile.png`)
   - **Purpose:** Professional headshot / profile picture displayed in the Hero and About sections.
   - **Recommended Dimensions:** Square aspect ratio (e.g., 600x600 px or 800x800 px).
   - **Format:** JPG, PNG, or WebP.
   - **Destination:** `assets/profile.jpg`

> **Note:** The website includes a built-in modern SVG developer avatar fallback so the site looks complete and visually polished immediately upon deployment. Once you add your `profile.jpg`, it will seamlessly display your real photo.
